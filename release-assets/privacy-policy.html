RustDesk Harmony 隐私政策

版本：1.0.0　生效日期：2026-07-22　开发者：ponyrun

本应用是兼容 RustDesk 协议的第三方远程桌面客户端，并非 RustDesk 官方产品。

一、处理的数据

仅在用户主动使用对应功能时，应用会处理远端设备 ID、设备名称、服务器地址和公钥、Server Pro 用户名与访问令牌、连接密码、地址簿与局域网设备信息，以及用户主动发送或接收的聊天和剪贴板文本。

二、目的与传输对象

数据用于建立用户指定的远程控制会话、登录用户配置的 Server Pro、同步设备列表、搜索同一局域网内的兼容设备以及完成聊天和剪贴板交换。网络数据发送至用户配置或选择的 RustDesk/Server Pro 服务器和远端设备；开发者不运营默认数据收集服务器，也不集成广告或分析 SDK。

三、本地存储与安全

远端 ID、设备名称和服务器配置保存在 HarmonyOS Preferences。仅在用户勾选“记住连接密码”时，连接密码会写入 HarmonyOS Asset Store，并设置为设备解锁后可访问。Server Pro 密码不会持久化，访问令牌只保存在当前进程内存中。

四、HTTP 风险

应用默认不允许使用 HTTP 登录 Server Pro。若用户主动开启“允许 HTTP / 不安全 TLS”，登录凭据可能缺少传输层保护；该功能只应在用户信任的隔离内网中使用。

五、权限与剪贴板

应用仅声明网络访问权限，不申请受限的剪贴板读取权限。本机到远端的剪贴板发送需要用户主动粘贴和确认；远端到本机的文本仅在已建立的会话中写入系统剪贴板。

六、保存期限与删除

本地数据保存至用户删除对应主机、在应用隐私政策页面点击清除本地数据或卸载应用。Server Pro 中的账户和地址簿由用户所选服务器管理，用户应通过该服务器管理员提供的渠道查询、更正或删除。

七、未成年人、政策变更与联系

本应用不面向未满十四周岁的儿童提供专门服务。政策发生实质变化时，应用会更新生效日期并重新征求同意。用户可通过华为应用市场详情页展示的开发者联系方式联系开发者。

发布前请将本文件部署到开发者可长期访问的 HTTPS 地址，并将同一地址填写到华为应用市场隐私政策字段。
